# 课程学习与开源调研

调研日期：2026-10-02。项目最终名称：**All-in-One Video Downloader**。

## 指定课程

1. [项目总览](https://www.codefather.cn/course/2027618983506640897/section/2036048069035851777)：读取页面公开 HTML 中的正文。课程以 Vue 3、FastAPI、yt-dlp、SQLite、DeepSeek 构建视频下载总结器；核心链路为链接解析 → 格式选择 → 服务端下载 → 文件交付，以及字幕 → 摘要 → 思维导图 → 问答。课程同时介绍认证、Stripe 与 SEO。
2. [项目学习大纲](https://www.codefather.cn/course/2027618983506640897/section/2036047875493888002)：读取页面公开 HTML 中的正文。学习顺序为需求与方案、核心功能、总结、扩展、页面优化、SEO、支付、部署。落实“方案沉淀后编码、每个功能提交、测试验证”，采用 Nginx 托管前端和代理长连接。

页面显示登录提示，但上述两节公开 HTML 已提供正文；没有访问付费章节或登录账号。本项目针对个人自托管使用，不纳入课程里的会员付费业务。项目独立实现，不复制课程项目源代码。

## 差异化

- “视频收纳”而非只交付一个文件：合集、星标、标签、笔记、播放器、Markdown 资料卡。
- 四个场景预设：日常收藏、高清存档、轻量通勤、音频口袋。
- 灵感剪辑：下载后用 FFmpeg 精确截取选定时间，生成独立片段。
- 稍后再下：预约时间、暂停/继续、失败重试、限速、重复链接提示。
- 学习花园：导入 SRT/VTT/TXT 或读取下载字幕，提取本地要点；配置 DeepSeek 后可生成 AI 摘要。无字幕时明确提示，不能伪造内容。
- 柔和、低干扰的中文界面，真实空状态，支持窄屏与键盘操作。
